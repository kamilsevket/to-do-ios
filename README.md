# To-Do iOS

Simple to do app with modern UI and gamification for completing tasks.

## Features

- Modern and clean UI design
- Task management (create, edit, delete, complete)
- Gamification elements for task completion
- Smooth animations and transitions

## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Installation

1. Clone the repository
```bash
git clone https://github.com/kamilsevket/to-do-ios.git
```

2. Open `ToDo.xcodeproj` in Xcode

3. Build and run the project

## Architecture

The app follows MVVM (Model-View-ViewModel) architecture pattern with SwiftUI.
